Expansion and period API

ExactWKB.CoalescentTurningPoints — Type
CoalescentTurningPoints(energy, z, separation)

Thrown by spectral_cycles when the energy E sits at (or numerically too close to) a critical value of the potential, so two turning points coalesce near z (separation separation; a multiple root reports separation = 0). The WKB cycle data is singular there - perturb E away from the critical value. Degenerate-Weber local models are deliberately out of the spectral layer's scope.

ExactWKB.ContourError — Type
ContourError(msg)

Thrown by period integration when a contour is ill-posed for the branch bookkeeping: a vertex sitting on a turning point (for a closed contour), or a step across which the √Q branch cannot be tracked unambiguously.

ExactWKB.InvalidPotential — Type
InvalidPotential(msg)

ExactWKB.QuantizationError — Type
QuantizationError(msg)

Thrown by wkb_eigenvalue when the numerical quantization solver fails to converge (bad seed, coalescing turning points along the solver path, or an n that selects no eigenvalue), and by quantization_condition when the spectral-cycle layout at E does not match the requested condition (no well cycle, or a multi-well problem where a single-well condition was requested).

TracingFailed(msg)

Thrown by the Stokes-graph tracer when a line neither hits a turning point nor escapes to infinity within the mass budget (max_mass). Pass allow_incomplete = true to stokes_graph to retain the partial line instead.

ExactWKB.UnsupportedTurningPoint — Type
UnsupportedTurningPoint(z, order)

Thrown when an operation that only handles simple turning points meets one of higher order at z - e.g. the WKB recursion evaluation or the Stokes tracer at a double turning point. The point is still classified correctly by turning_points; only the downstream local model is missing (Weber local models are deferred).

ExactWKB.AbstractSchrodingerProblem — Type
AbstractSchrodingerProblem

Supertype of the one-dimensional problems $ħ²ψ″ = Q(z)ψ$ the package traces: SchrodingerProblem (polynomial Q) and RationalProblem (rational Q, i.e. Q with poles). Everything the Stokes-geometry layer needs is reached through four methods - prob(z), q_derivative_at, q_taylor_at and turning_points - so a new potential class is one file, not a rewrite.

source
ExactWKB.SchrodingerProblem — Type
SchrodingerProblem{T}

A one-dimensional Schrödinger problem $ħ²ψ″ = Q(z)ψ$ with $Q(z) = V(z) − E$. The potential V is a polynomial in the variable var (default :z) stored by its coefficients v_coeffs in ascending order (v_coeffs[k] multiplies $z^{k-1}$); energy is $E$. Immutable: with_energy returns a new problem.

The coefficient type T is generic - exact Rational/Int and real floats are all first-class. Construction throws InvalidPotential on an empty coefficient vector or on a Q that is identically constant (no turning points).

Examples

airy   = SchrodingerProblem([0, 1])                       # Q = z
harm   = SchrodingerProblem([0, 0, 1]; energy = 1)        # Q = z² − 1
dwell  = SchrodingerProblem([3//4, 0, -2, 0, 1])          # Q = (z²−1)² − 1/4
airy(2.0)                                                 # Q(2) = 2.0

ExactWKB.asymptotic_directions — Method
asymptotic_directions(prob, theta; pole = 0) -> Vector

The directions in which Stokes lines run into a singularity of Q at phase theta. Locally Q ~ c·ζ^e (ζ = z − p at a finite pole p, ζ = 1/z inverted at infinity), and Im[e^{−iθ}∫√Q] = 0 puts |e + 2| directions at

arg ζ = (2θ − arg c + 2πk)/(e + 2) ,   k = 0 … |e+2| − 1 .

pole = 0 selects infinity (e = degree(prob), so a degree-d polynomial gets the familiar d + 2 asymptotic directions); pole = j ≥ 1 selects the j-th finite pole of a RationalProblem, where e = −m_j and the count is m_j − 2. The returned angles are the marked points of the boundary circle at that singularity.

A double pole gives e + 2 = 0 and the empty vector: it is a puncture, carrying no marked points, and the trajectories spiral into it instead of approaching a direction; closed trajectories require separate analysis.

ExactWKB.q_taylor_at — Method
q_taylor_at(prob::SchrodingerProblem, z0) -> Vector

The Taylor coefficients of $Q$ about z0 in ascending order: the returned t satisfies $Q(z) = Σ_k t[k+1] (z − z_0)^k$, so t[1] = Q(z₀), t[2] = Q′(z₀) and t[m+1] = Q^{(m)}(z₀)/m!.

Computed by repeated synthetic division, so the result is exact whenever the coefficient type and z0 are (Rational, Integer). This is how the leading coefficient $c_m$ of a turning point of order m is read off - the datum that sets its Stokes-ray directions (see stokes_graph).

ExactWKB.RationalProblem — Type
RationalProblem(n_coeffs, poles, pole_orders; var = :z)

Represent Q = N(z)/prod((z-p)^m) with ascending numerator coefficients. Pole locations and orders are supplied data. Finite orders must be at least two. The exponent of Q at infinity must be at least -1. Supports classical periods and numerical tracing, not the Riccati recursion. Throws InvalidPotential for unsupported or cancelling pole data.

ExactWKB.degree — Method
degree(prob::RationalProblem) -> Int

The exponent of Q at infinity: Q ~ a·z^{degree}, i.e. the numerator degree minus the total pole order. May be negative. This is the same quantity degree returns for a polynomial problem, so asymptotic_directions is one formula for both; the pole order of Q dz² at infinity is degree + 4.

ExactWKB.turning_points — Method
turning_points(prob::AbstractSchrodingerProblem; cluster_tol = nothing)

Locate zeros of the polynomial numerator and report their algebraic multiplicities. Multiplicity refers to the exact polynomial represented by the supplied coefficients. Floating coefficients are treated as exact binary rationals for this purpose. Root positions are numerical and follow the coefficient precision. cluster_tol is a separation guard, never permission to merge roots. Throws Resurgence.InvalidArgument when distinct roots are numerically unresolved.

ExactWKB.evaluate_s_odd — Method
evaluate_s_odd(w::WKBExpansion, z; branch = 1, sqrt_q = nothing) -> FormalSeries

The odd part S_odd(z, ħ) = Σ_{m odd} S_m(z) ħ^m evaluated at z, returned as a Resurgence.FormalSeries in :ħ with power_offset = -1 and zero even coefficients - exactly the integrand-at-a-point of the Voros/quantum-period machinery. branch = ±1 picks the sign of the principal √Q(z); pass sqrt_q to supply a branch value tracked from elsewhere (used by period_integral).

source
ExactWKB.even_odd_residual — Method
even_odd_residual(w::WKBExpansion; z0 = nothing) -> Real

Numerical check of the exact reduction S_even = −½ ∂_z log S_odd, in the division-free form S_even·S_odd + ½ S_odd′ = 0. Returns the largest absolute coefficient of the left-hand side as an ħ-series evaluated at a generic point z0 (default a fixed off-axis complex point); ≈ 0 to the computed order.

s_odd_terms(w::WKBExpansion) -> Vector{<:NamedTuple}

The odd WKB coefficients S_{-1}, S_1, S_3, … as AbstractAlgebra-free descriptions: each a (m, numerator, q_power) with numerator the ascending coefficient vector of p_m(z) (plain numbers) and S_m = p_m(z)·√Q / Q^{q_power} (sqrt_pow is always 1 for odd m).

ExactWKB.wkb_derivative — Method
wkb_derivative(w::WKBExpansion; wrt = :energy, index = 0) -> WKBDerivative

Differentiate the Riccati coefficients of w with respect to one parameter of the potential: wrt = :energy gives ∂/∂E (so ∂Q = −1), and wrt = :coefficient with index = k gives ∂/∂v_k, the coefficient of z^k in V (so ∂Q = z^k).

Exact: the recursion is differentiated, not the code that evaluates it, so each ∂S_m is again a rational function of the same shape and is integrated by wkb_period over the same contour and branch table as S_m.

source
ExactWKB.wkb_expansion — Method
wkb_expansion(prob::SchrodingerProblem; order = 10, arithmetic = :auto)
    -> WKBExpansion

Compute the Riccati coefficients S₋₁ … S_order for real polynomial coefficients. Complex evaluation points are supported; nonreal coefficients throw InvalidPotential. arithmetic selects the numerator ring: :exact (QQ, requires rational/integer Q), :bigfloat (RealField), or :auto (exact when the potential coefficients are exact, else BigFloat). Exact-ring blow-up in the numerator degree is the known cost driver at high order.

ExactWKB.period_derivative — Method
period_derivative(prob::AbstractSchrodingerProblem, contour, dQ; closed = true)
    -> Complex

$∂_λ$ of the classical period $∮√Q\,dz$ along contour, for any parameter λ entering only through Q: dQ is a callable giving $∂_λ Q(z)$, and the integral is $∮ ∂_λQ / (2√Q)\,dz$ over the same contour and branch table as period_integral.

Frozen contour, so this is exact only for a closed cycle - see the ledger at the top of this file. dQ = z -> -1 is $∂/∂E$ for a SchrodingerProblem; dQ = z -> z^k is $∂/∂v_k$. Unlike wkb_derivative this needs no Riccati algebra, so it also covers a RationalProblem, where λ is whichever parameter the caller differentiates Q by.

ExactWKB.period_integral — Method
period_integral(prob::AbstractSchrodingerProblem, contour; closed = true) -> Complex

The classical period $∮ √Q\,dz$ ($= v_{-1}$) along the piecewise-linear contour (a vector of complex vertices). With closed = true the contour is closed back to its first vertex. The √Q branch is tracked continuously; a vertex sitting on a turning point, or a contour enclosing an odd number of turning points (so √Q is not single-valued), throws ContourError. Precision follows the contour's float type. atol and rtol control quadrature only. An unmet quadrature error target raises ContourError.

source
ExactWKB.wkb_period — Method
wkb_period(w::WKBExpansion, contour, m; closed = true) -> Complex
wkb_period(dw::WKBDerivative, contour, m; closed = true) -> Complex

The order-m quantum period $∮ S_m\,dz$ along contour, using the same √Q branch tracking as period_integral. m = -1 reproduces the classical period.

Given a WKBDerivative instead, the same integral of $∂S_m$ - that is, $∂_λ$ of the order-m period, taken at frozen contour (see the ledger above).

ExactWKB.full_series — Method
full_series(vs::VorosSymbol) -> FormalSeries

The complete Voros symbol $∮S_odd = v_{-1}ħ^{-1} + v₁ħ + v₃ħ³ + …$ as one FormalSeries with power_offset = -1 (the $ħ^0$ Maslov slot is zero - that index is carried by the quantization convention, not the summable series).

ExactWKB.quantum_series — Method
quantum_series(vs::VorosSymbol) -> FormalSeries

The quantum tail $v₁ħ + v₃ħ³ + …$ (power offset 1, even coefficients zero). This is the object to hand to Resurgence's borel/pade/laplace_sum. Because the odd-only coefficients alternate with exact zeros, an equal-degree [n/n] Padé is degenerate - pass order or reduce = true to pade.

source
ExactWKB.voros_symbol — Method
voros_symbol(w::WKBExpansion, contour; closed = true, atol = nothing,
             rtol = nothing) -> VorosSymbol

The Voros symbol of the cycle contour: computes the quantum periods v_m = ∮ S_m dz for m = -1, 1, …, order with the shared √Q branch tracking of wkb_period. The even periods v₂, v₄, … are asserted ≈ 0 (tolerance atol, default scaled to the period magnitudes) and stored as exact zero. rtol passes through to the quadrature of each period (default √eps of the working float - override to trade precision for speed in energy sweeps).

Given a WKBDerivative, construct the formal parameter-derivative symbol. Summing that series is generally different from differentiating a finite Padé approximation of the primal symbol. No numerical derivative identity is asserted here.

source
ExactWKB.voros_value — Method
voros_value(vs::VorosSymbol, ħ; theta = 0, side = :median, tilt = 1//100, kwargs...)

Estimate exp(classical_period/hbar + summed_tail) on explicit regular rays. :plus and :minus use theta + tilt and theta - tilt. :median averages their logarithmic tail sums before exponentiation. These finite-approximant samples are not certified physical lateral sums. Order and tilt stability require independent checks; no exact deformation is assumed.
